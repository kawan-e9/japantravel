# GitHub Pages PWA Bundle

Live URL: https://kawan-e9.github.io/kawan-e9/

## Supporting Files Included
- `sw.js` — Service Worker untuk *caching* aset utama dan dukungan mode *standalone* / *offline*.
- `manifest.json` — Konfigurasi Web App Manifest.
- `icon-192.png` & `icon-512.png` — Ikon aplikasi PNG.
- `favicon.ico` — Ikon *tab browser*.
- `og-preview.svg` — Gambar pratinjau tautan / *open graph*.
- `robots.txt` & `sitemap.xml` — Konfigurasi perayapan & *sitemap* GitHub Pages.
- `tailwind.min.css` — Berkas utilitas CSS pendukung agar tidak terjadi *404* jika direferensikan.
